# 侧栏按钮改为 ds-bot 胶囊风格 —— 交接文档（2026-10-24）

来源：`dsh-web-ui-linker` 已于 2026-10-24 完成同款改造（其 `lib/client.js` 的 `.wul-button`），
本仓库的侧栏「任务队列」按钮（`.gq-side`）按同一方法处理。

## 风格出处

ds-bot 插件侧栏底部「DS Bot」返回按钮（`.bt-return`）的原始 CSS（摘自其 `client.js`）：

```css
.bt-return{display:inline-flex;align-items:center;justify-content:center;gap:8px;min-height:36px;padding:0 14px;border:0;border-radius:999px;background:none;color:inherit;font:inherit;font-size:14px;line-height:20px;cursor:pointer;transition:background-color .12s ease}
.bt-return:hover{background:rgba(127,127,127,.14)}
.bt-return:active{transform:scale(.96)}
```

要点：**无描边、透明底、999px 胶囊圆角、36px 高、14px/20px 文字、hover 灰罩、按下 `scale(.96)`、
`background-color` 过渡**。ds-bot 按钮自带的头像图片**不引入**——只保留本插件自己的文字内容。

## dsh-web-ui-linker 的落地结果（参照）

```css
.wul-button{display:inline-flex;align-items:center;justify-content:center;gap:8px;width:100%;min-width:0;box-sizing:border-box;min-height:36px;padding:0 14px;border:0;border-radius:999px;background:none;color:inherit;font:inherit;font-size:14px;line-height:20px;cursor:pointer;transition:background-color .12s ease}
.wul-button:hover{background:rgba(127,127,127,.14)}
.wul-button:active:not(:disabled){transform:scale(.96)}
```

（该按钮原有描边，错误/成功态从描边换色改为文字着色；本插件 `.gq-side` 没有状态描边，无需此步。）

## 本仓库的具体改法（`src/client/styles.ts`）

当前 `.gq-side` 与弹层按钮 `.gq-root button` **共用**规则（第 4、5、6、8 行的并列选择器），
直接改会连带弹层所有按钮。因此：

1. 从共用规则中**拆出** `.gq-side`：
   - 第 5 行 `.gq-root button,.gq-side{border:…;border-radius:7px;background:…;padding:7px 10px;…}` → 只留 `.gq-root button`；
   - 第 6 行 `.gq-root button:hover,.gq-side:hover{filter:brightness(1.13)}` → 只留 `.gq-root button:hover`；
   - 第 4 行（`font:inherit;color:inherit`）与第 8 行（`:focus-visible` 描边）可保留 `.gq-side`。
2. 把第 26 行的旧侧栏规则替换为 ds-bot 胶囊风格：

```css
.gq-side{display:inline-flex;align-items:center;justify-content:center;gap:8px;min-height:36px;width:100%;margin:4px 0;box-sizing:border-box;padding:0 14px;border:0;border-radius:999px;background:none;color:inherit;font:inherit;font-size:14px;line-height:20px;cursor:pointer;transition:background-color .12s ease}
.gq-side:hover{background:rgba(127,127,127,.14)}
.gq-side:active{transform:scale(.96)}
```

3. **不改** `QueueButton.tsx` 的文字内容（「任务队列 (运行N · 待执行M)」及加载/异常态文案），不加图标/图片。
4. 弹层（`.gq-root` 内）所有按钮样式保持原样。

## 验收标准

- `npm run typecheck`、`npm test`（pretest 会先 `npm run build`）全部通过；`lib/` 为最新构建产物
  （桌面 profile 的 node_modules 是指向本仓库的 junction，GUI 重载后生效）。
- 桌面 GUI 侧栏底部「任务队列」按钮变为透明胶囊：无描边、圆角 999px、36px 高、14px 文字，
  hover 出现 `rgba(127,127,127,.14)` 灰罩，按下 `scale(.96)`；与 dsh-web-ui-linker 的
  「打开 Web UI」按钮、ds-bot 的「DS Bot」按钮观感一致。
- 打开队列弹层，其中按钮外观与改动前完全一致。
- CHANGELOG.md 增补一条样式变更说明；README 若有旧样式描述一并同步。
