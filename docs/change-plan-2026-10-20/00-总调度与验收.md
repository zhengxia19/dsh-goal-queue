## 2. 必须保持的全局验收断言

- **G01 不重复执行**：未知是否提交的普通 Prompt、`/goal`、`/goal resume` 不会自动重试；同一恢复授权只触发一次命令。
- **G02 暂停边界**：按用户收到的暂停反馈区分“未提交”的任务和“可能已经提交”的任务；未提交任务不得偷偷执行，已提交 Agent 不会被误称取消。
- **G03 并发上限**：新的派发仅在可信 Session/队列状态允许时进行；降低并发上限不停止旧任务；原 Session 复用后按唯一 Session ID 计数，不双重计数。
- **G04 状态失败关闭**：配置 reading/error、CAS 失败、connection reset、版本迁移错误后不可派发；恢复读取成功并不自动授权。
- **G05 恢复不破坏历史**：成功、失败、跳过和重试都保留可追溯 Session ID；恢复必须有 Host 状态/Goal ID 证据。
- **G06 完成语义不变**：Goal 完成依据 Goal ID + `phase=complete` + Session idle；普通模式需 observed running→idle；不能把模型输出或 UI 关闭当成完成。
- **G07 数据兼容**：历史 `version=1`、`activeId`、无标题配置的队列可安全读取；损坏数据拒绝写入；旧数据不会被迁移清空。
- **G08 标题隔离**：仅用户勾选时发送独立无工具 LLM 请求，不增加普通 Prompt 或 Goal 执行；无工具、无任务 Session ID；原生 `sessionTitle` 保持唯一标题权威。
- **G09 测试边界**：CI 证明自动化通过；Windows Desktop 的安装、连接、会话复用、命令、标题、卸载需单独证据。
